# HABIT.coo Shopify theme

Connect Shopify to this repository's `habit-shopify` branch. Theme folders are at the branch root. This branch is the canonical theme source after connecting; `main` retains the original portfolio package.

GitHub Actions runs Shopify Theme Check and JavaScript syntax validation after each push. Passing these static checks does not prove cart, checkout, mobile rendering or app integration behavior.

Independent portfolio demonstration prepared with AI assistance. Sora and HABIT versions are the same practice project, not separate client builds. Demo products and prices are fictional.

After connecting the new draft theme, select the `HABIT Demo` collection under Featured again, save, and test variants, quantities, gift messages and cart updates in the storefront preview. Settings edited in a previously uploaded ZIP theme are not automatically copied to this theme.

Do not add credentials, customer records or private store details to this public repository. Use development store test payments only.
