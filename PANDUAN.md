# Cara memakai demo ini

1. Ekstrak paket ZIP utama.
2. Buka `OPEN_PREVIEW.html` (satu file) atau `preview/index.html` di Safari/Chrome untuk melihat dan mencoba tampilan: klik produk, pilih varian, isi pesan, tambah ke bag, buka bag, hapus produk, dan ubah urutan harga.
3. Preview lokal bukan toko Shopify. Bag hanya simulasi, hilang saat reload, dan tidak menerima pembayaran.
4. File `sora-theme.zip` khusus untuk diunggah sebagai tema belum dipublikasikan di toko pengembangan/tes Shopify milikmu.
5. Tambahkan contoh produk dari `sample-products.json` secara manual; file JSON ini bukan file import.
6. Buat koleksi, masukkan produknya, lalu pilih koleksi itu pada Featured di editor tema.
7. Uji dengan checklist QA.md. Sesudah lolos, ambil screenshot Shopify atau tautan preview yang bisa diakses perekrut.
8. Siapkan penjelasan: fungsi layout, template JSON, section Liquid, snippet kartu produk, form produk/keranjang, dan JS pilihan varian. Pelajari dulu agar mampu menjawab interview.

## Catatan portofolio
Ini 1 proyek latihan baru dengan bantuan AI, bukan proyek klien lama dan bukan 2–3 toko. Jangan kirim sebagai pengalaman Shopify komersial. Kode tersedia di repositori GitHub Meta2323/sora-shopify-demo. Tema belum dipasang ke Shopify.
